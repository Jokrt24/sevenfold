# 七重 · SEVENFOLD

七宗罪与七美德的自我观察测试。

网址：https://jokrt24.github.io/sevenfold/

它问的都是很具体的事：开会时你怎么反应、朋友报喜时你心里第一下是什么、深夜你会不会又刷到两点。答完会给出一个判词——你最像哪一宗罪，或者哪一种德。

判词只是开头。比如判词是嫉妒，页面会继续把嫉妒拆成四种：贬抑传播、优越比较、怨恨敌意、幸灾乐祸，告诉你哪一种最重，并且写成你能对上号的动作，不是形容词。

两种玩法：

**简约探索**，56 题，七分钟左右。给出判词、天平、十四面镜、形态、七对刻度、解读、日常信号。

**深度探索**，161 题，十八分钟左右。在简约的基础上，每个面多问强度和代价两题，最后把十四个轴、四十九个面全部展开——每个面的频率、强度、代价分开列，还排出最贵的三个面和一份总评。

整站就是一个 html 文件。没有服务器、没有数据库，也不发任何请求，所有计算在浏览器里完成。答完的答案编码进链接本身，发给别人，他自己打开就能看到你的结果。

这个仓库里放的是静音版，不含音频，280 KB，手机打开也很快。

页面与代码由 AI 协作完成，我负责提需求、改内容、把它传上来。
