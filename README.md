# 七重 · SEVENFOLD

七宗罪与七美德的自我观察测试。

网址：https://jokrt24.github.io/sevenfold/

## 它问什么

不是「你是否嫉妒」，而是具体的事：同事升职你说了什么、开会被点名你什么反应、深夜刷手机停不停。

开始前先选身份——**学生**或**在职**。题目会换成你熟悉的场景：同事→同学，领导→老师，方案→作业。

题目分三种问法，选项也各不相同：

- **你的做法**：这种事多久发生一次（从没／一两次／有时／经常／几乎总是）
- **当时的感觉**：那一刻心里或身上的反应（完全没有／很轻／一般／明显／很强烈）
- **后来发生的事**：已经发生的结果（没有／有过一次／有过几次／经常发生／几乎每次都是）

## 两种玩法

**简约探索**：56 题，约 7 分钟。给出判词、天平、十四面镜、形态、七对刻度、解读、日常信号。

**深度探索**：308 题，约 30 分钟。49 个面，每个面 6 道题——做法 2 道、感觉 2 道、后果 2 道。结果是十四个轴、四十九个面全部展开，每个面的频率／强度／代价分开列，另加最贵的三个面、总评、十四道情境对照。

## 结果是什么

先给一个判词：你最像哪一宗罪，或哪一种德。然后把这一项拆开——比如判词是嫉妒，会拆成贬抑传播、优越比较、怨恨敌意、幸灾乐祸四个面，哪个重就写哪个，写成能对上号的动作，不是形容词。
